Open **Discounts**. The **Live right now** box at the top shows what customers get today.

Discounts only apply when your site takes payment on its own checkout through a payment provider service. If the page warns that it has no effect, the active checkout does not support discounts.

## Create one

1. Press to create a discount and give it a **Name**.
2. Choose what it **Applies To**:
   - **Coupon code (whole basket):** customers enter a code.
   - **Sitewide (whole basket):** everyone gets it automatically.
   - **Specific products, categories or brands:** including ones added later.
3. For a coupon, enter the **Coupon Code** (letters, numbers, hyphens and underscores). Set **Total Uses Allowed** and **Uses Per Customer**, or leave them blank for unlimited.
4. Choose the **Discount Type**, **Percentage** or **Fixed amount**, and the **Value**.
5. Optionally set a **Minimum Spend (inc. VAT)**, which is the basket total before the discount and delivery.
6. Tick **Free delivery** to waive the delivery charge. Use a value of 0 with it to waive delivery only. With a minimum spend, this gives free delivery over a certain amount.
7. Set **Starts** and **Ends**, or leave them blank to start now and run until you stop it.
8. Make sure **Active** is ticked and save.

Switch **Active** off to pause a discount without deleting it.

## When discounts overlap

- A sitewide discount overrides every other discount, and coupon codes are refused while it runs.
- If several product discounts cover the same product, the biggest applies.
- A customer who enters a coupon loses the product discounts on that basket.

**Baskets** shows what shoppers have put in their baskets, so you can see interest in products even when no order is placed.

## The three lists

- **Active Baskets:** baskets with recent activity.
- **Abandoned Baskets:** baskets with no activity for the number of hours set under **Basket Abandoned Threshold (hours)** in the shop settings.
- **Converted Baskets:** baskets that became an order in the last 7 days.

Each row shows a short session reference, how many items it holds and its value. Open a row to see the products, options, quantities and prices inside. Baskets belong to a browsing session, so there is no customer name or email here.

## Tidy up

**Delete** removes one basket. **Clean up old baskets**, on the Abandoned list, asks how many days and then deletes every abandoned basket older than that. It starts at 30 days. This cannot be undone.
